# 🔐 Face ID + Blockchain Verification

A computer vision and blockchain-based system for face identification, reverse image search, and tamper-evident verification.

## 🚀 Project Pipeline

```text
Input Face Image
       ↓
Face Detection (YuNet)
       ↓
Face Feature Extraction (SFace)
       ↓
Reverse Image Search
       ↓
Candidate Web Images
       ↓
Face Similarity Comparison
       ↓
Match Found
       ↓
SHA-256 Fingerprint
       ↓
Smart Contract
       ↓
Blockchain Verification
